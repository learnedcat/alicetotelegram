# Навык Алисы "Список покупок" с отправкой сообщений в Telegram

Небольшой сервис на Go, который принимает команды от **Алисы** и добавляет товары в **список покупок в Telegram**. Для интеграции этого сервиса с Алисой необходимо создать навык в панели Яндекс.Диалоги.

---

## Возможности

* Принимает голосовые команды вида:

  * «Алиса, надо купить хлеб и молоко»
  * «Добавь в список покупок сыр»
* Очищает фразу от служебных слов
* Отправляет список покупок в Telegram
* Редактирует одно сообщение в течение 30 минут
В случае, если Алиса перехватывает обсуждение, может потребоваться запустить навык через "Алиса, запусти навык Список покупок".

---

## Как это работает

1. Алиса отправляет POST‑запрос
2. Сервер парсит JSON и нормализует текст
3. Сообщение в Telegram:

   * либо отправляется новым
   * либо редактируется, если прошло меньше 30 минут

## Переменные окружения

Перед запуском необходимо задать:

```bash
export TELEGRAM_BOT_TOKEN=123456:ABCDEF...
export TELEGRAM_CHAT_ID=123456789
```

---

## Запуск

```bash
docker compose up -d --build
```

Сервер требуется запускать на VPS, имеющем домен, например, http://yout-domain.com. Этот домен указывается в настройках навыка в консоли Яндекс.Диалоги.

---

## Настройки

Время, в течение которого сообщение редактируется:

```go
const editThreshold = 30 * time.Minute
```

Таймаут Telegram‑запросов:

```go
const tgTimeout = 5 * time.Second
```

Список служебных слов:

```go
cutWords := []string{
    "алиса",
    "надо",
    "купить",
    "список",
    "покупок",
}
```
